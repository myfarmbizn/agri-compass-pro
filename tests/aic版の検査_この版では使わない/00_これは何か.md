# AIC版の検査（この版では使わない）

ここにあるのは、土台にした農業経営コンパス AIC版のために書かれた検査です。
現役農家版では、次の理由でそのままでは通りません。

- 立場（5つのペルソナ）で順路が変わる前提だが、この版は順路が1本
- 学校別の入口（sites/）と事務局向け（jimukyoku/）を見に行くが、この版には無い
- 経営力チェック・独立と雇用の比較・給与の手取り換算・AIに相談する を見に行くが、この版には無い
- 例題（presets）を読み込むが、この版は例題を置いていない

消さずに残してあるのは、中身に検査の作り方の知恵が入っているためです。
AIC版そのものを直すときは、`agri-compass-aic` のほうで走らせてください。

現役農家版の検査は、1つ上の階層にあります。

- `verify_uchite.js` … 打ち手の機械の検算（手計算との突き合わせを含む）
- `verify_michi.js` … 進む道が1本か
- `verify_kotoba.js` … 画面に出る日本語の作り
- `verify_presets.js`（tools/） … 例題の検算。この版は例題を置いていないので使わない
- `try_gamen.py` … 全ページをブラウザで開いて押して回る
