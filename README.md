# マイファーム農業経営コンパス 現役農家版

いま農業をしている方が、自分の記録を自分の見通しに変えるための道具。

土台は AIC版（`agri-compass-aic`）。計算エンジンと収録データはそのまま引き継ぎ、
対象を現役のプロ農家1本に絞って、入口・順路・つながりを作り替えた。

- 公開URL: https://myfarmbizn.github.io/agri-compass-pro/
- 土台の版: https://myfarmbizn.github.io/agri-compass-aic/ （引き続き運用。こちらは触らない）
- 設計: `07_現役農家版コンパス\設計\01_設計_現役農家版コンパス_第1版.md`
- 全体地図: `07_現役農家版コンパス\設計\00_全体地図_現役農家版コンパス_v1.html`

## AIC版との違い

| | AIC版 | 現役農家版 |
|---|---|---|
| 対象 | 就農を考えている人〜就農して間もない人（4段階） | 現役のプロ農家1本 |
| 入口 | トップで目標金額のつまみ→必要面積 | 品目と単価（`tools/hinmoku.html`）。品目と面積を入れるとその場で1年の見通し |
| 立場の選び分け | 5つの立場で順路とページが変わる | 無し。順路は1本（7段） |
| 実績の扱い | 実績の診断は所得と時給を出すだけ | 実績を計算の前提へ書き戻せる（この版の中心） |
| 記録の取り込み | 無し | `tools/kiroku.html`。伝票・ノート・書き出し・決算書をAIが読み取る |
| なりたい姿 | 無し | `tools/nozomi.html`。何年後にいくら、どれくらい働きたいか |
| 計画の直しどころ | 無し（外部AIへ貼る文章を作るだけ） | `tools/teian.html`。AIが打ち手を選び、この道具が計算し直す |
| 計画書 | A4にまとめて印刷 | 同じ。加えて書きもれと食い違いの読み合わせ |
| 立ち上がりの割合 | 1年目70%などの見込み | 初年から100%（もう満作のため） |
| 保存の名前空間 | myfarm-agri-compass-aic | myfarm-agri-compass-pro（AIC版のデータを壊さないため） |
| 操作の記録の送信 | マイファームへ自動送信 | 送らない（この版の送り先が無いため。端末に残り、書き出せる） |
| 入れた数字の置き場所 | 端末のブラウザだけ | 端末＋マイファームのサーバ（合言葉を入れたとき）。端末を替えても続きから使える |

計算（`sim_engine.js`）と収録データ（`data_*.js` の数値）は変えていない。
同じ入力ならAIC版と同じ数字が出る。

## 7つの段

| 段 | 画面 | 何をする |
|---|---|---|
| 1 | `tools/hinmoku.html` | 品目に印を付けて面積を入れる。その場で1年の見通しが出る |
| 2 | `tools/kiroku.html` | 伝票・ノートの写真・書き出し・決算書を送る。AIが読み取る |
| 3 | `tools/checkup.html` | 申告書の数字から所得と時給。そのまま計算の前提にできる |
| 4 | `tools/sakutsuke.html` ほか4枚 | 作付け・収支・資金繰り・投資・災害への備え |
| 5 | `tools/nozomi.html` | 何年後にいくら、どれくらい働きたいか、手放したくないもの |
| 6 | `tools/teian.html` | 計画の直しどころ。AIは打ち手を選び、金額は機械が計算する |
| 7 | `tools/keikaku.html` | A4の計画書。書きもれと食い違いの読み合わせ |

`index.html` は行き先を渡すだけの1枚で、開くと段1へ移る。

## 出どころの札

すべての数字に出どころが付く。`assets/js/data_okinawa.js` の `flagLabel` が正典。

| 札 | 意味 |
|---|---|
| （なし） | 県平均。公表資料の値。出典が引ける |
| 実績から（2025年） | 実績の診断に入れた申告書の数字から機械が作った値 |
| 記録から（12件・2025年） | 本人の記録をAIが読み取り、機械が数えて作った値 |
| 自分の値 | 品目と単価の画面で手で打った値 |
| 仮 | 出典なしの仮定値 |

`cropCustom.overrides` の値は、数だけ（手で打った値）と、
`{ v, jisseki|kiroku, nen, mai }`（実績や記録から作った値）の両方を受け取る。

## AIの扱い

AIは3か所で動く。呼び口は `assets/js/ai.js` の1本だけ。

1. 読み取り（段2）… 雑多な記録を決まった項目に写す
2. 直しどころ（段6）… 打ち手の型と強さを選ぶ。金額は返させない
3. 読み合わせ（段7）… 計画書の抜けと矛盾を挙げる

決まり。AIは抽出と選択だけ。ツール実行・外部取得の権限を与えない。
利用者の書類は資料として渡し、指示として扱わせない。出力はJSONで受け取り、機械で検証してから使う。
金額は必ず `sim_engine.js` が計算する。 打ち手を計画に当てる機械は `assets/js/uchite.js`。

AIの受け口（URLと8文字の合言葉）が設定されていないときは、見本の受け答えで動き、
画面に必ず「見本」と出す。段6では機械が決めた既定の3案（面積・単価・経費率）が必ず出る。

## サーバに預ける

合言葉（8文字）とサーバのURLを、記録を入れる画面の下にある「サーバの設定」へ入れると、
入れた数字がマイファームのサーバへ預けられ、端末を替えても続きから使えるようになる。
あわせて、記録の読み取りと計画の直しどころを、本物のAIが受け持つようになる。

設定を入れていないときは、これまでとまったく同じに動く。外へは1件も送らない。

| 何 | どこ |
|---|---|
| 画面側の窓口（`CORE.store` をくるむ） | `assets/js/db.js` |
| 表と預かる口 | `ツール本体/platform/db/migrations/057_compass_wo_azukaru.sql` |
| 受け口 | `ツール本体/platform/api/src/compass.mjs` |
| AI | `ツール本体/platform/api/src/compass_ai.mjs` |
| 置き方 | `aws/README.md` |
| 設計 | `07_現役農家版コンパス/設計/02_サーバに預ける設計_第1版.md` |

決まり。端末が正本で、サーバは預かり先。サーバが落ちても、電波が無くても、手元では動き続ける。
送るのはまとめて3秒待ってから。開いたときは、保存した時刻の新しいほうを残す。

## 検査

```
node tests/verify_uchite.js      # 打ち手の機械の検算（手計算との突き合わせを含む）
python tests/try_gamen.py        # 全ページをブラウザで開いて押して回る
python tests/try_saba.py         # 画面からサーバへ預けるところを通しで確かめる
```

`try_gamen.py` は配信を自分で立ち上げるので、先に何かを起動しておく必要はない。
中に4つの検査が入っている。全ページが開くか／消したページが残っていないか／
進む道が1本か／画面に出る日本語の作り。

手で触って見るときは `node tests/serve.js`（ポート8123）を立ち上げる。
python の `http.server` は連続実行で接続が切れて偽の不合格を出すため使わない。

AIC版のために書かれた検査17本は `tests/aic版の検査_この版では使わない/` に移してある
（立場・学校別の入口・例題を前提にしているため、この版では通らない）。

`python %USERPROFILE%\.claude\hooks\check_kinshigo.py .` で禁止語の検査も通す。
